# 道經第三十七章 · 无名

> 帛書第 81 章 · 王弼第 37 章

## 帛書原文

道恆无名 

侯王若守之 萬物將自化 

化而欲作 吾將貞之以无名之樸 

貞之以无名之樸 夫將不辱 

不辱以靜 天地將自正

## 王弼本對校

道常無為
:
而無不為。
:
侯王若能守之，萬物將自化。化而欲作，吾將鎮之以無名之樸。
:
無名之樸，夫亦將無欲。
:
不欲以靜，天下將自定。

## 杳眇疏

杳眇曰：

夫道之顯也，無名而無不名；道之隱也，無為而無不為。此章之旨，帛書與王弼本異文可玩，讀者不可以文字小異而忽之也。

帛書云「道恆无名」，王弼本易以「道常無為而無不為」。一則從體言，一則從用言。[[道恆無名]]者，道之質也，沖漠未朕，不可名號，故曰無名。[[無名萬物之始]]，斯之謂也。而[[道常無為而無不為]]者，道之運也，化生萬物而功成不居。體用一原，顯隱異名，而道未嘗二也。侯王若能守此道，萬物將自化——[[侯王守之萬物自化]]是也。

然萬物自化之中，化而欲作者起焉。欲作者，嗜欲萌動，有為之漸也。[[化而欲作]]，此萬物之通患，聖人之所以深慮也。

吾將貞之以無名之樸。貞者，正之、鎮之、定之也。[[無名之樸夫亦將無欲]]，河上公注云「聖人治天下，不以智治，不以力勝，返百姓於無欲之樸，使自定焉」，此之謂也。帛書云「貞之」，王弼本云「鎮之」。貞者，正其所以不正，非外加之制也；鎮者，靜其所以不靜，非力制之也。竊謂帛書「貞」字義長，蓋無名之樸非有術也，乃道之淳樸，足以正萬物之偏爾。

夫將不辱。不辱者，不為外物所累也。《[[天道]]》篇云「萬物無足以撓心」，斯不辱之旨乎？夫欲作者，以物累心者也；貞之於欲作之初，則心不被物累，不辱以靜，此自然而然之效也。

不辱以靜，天地將自正。帛書云「天地將自正」，王弼本云「天下將自定」。[[清靜為天下正]]，正者，各得其分、萬物自理之謂也。《[[侯王得一以為天下正]]》云得一則天下正，是知正者通天地人三才而言之，定者偏於治世之效爾。[[不辱以靜]]之「靜」字尤妙，靜者，萬動之宗；[[不辱]]者，靜之因；天地自正者，靜之果也。

《[[天之道]]》云「天之道，不單而善朕」，言天道無為，而萬物自歸其正。此章之義，歸乎一靜，靜之極，天地自正，萬物自定，無為之治，至此而備矣。

警曰：**守道者，守一「無名」爾。名不去，欲不絕，靜不可得也。**
