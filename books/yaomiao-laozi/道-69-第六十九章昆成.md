# 道經第二十五章 · 昆成

> 帛書第 69 章 · 王弼第 25 章

## 帛書原文

有物昆成 先天地生 

繡呵繆呵 獨立而不改 可以為天地母 

吾未知亓名 字之曰道 吾強為之名曰大 

大曰筮 筮曰遠 遠曰反 

道大 天大 地大 王亦大 

國中有四大 而王居一焉 

人法地 地法天 天法道 道法自然

## 王弼本對校

有物混成，先天地生。
:
寂兮寥兮，獨立而不改，
:
周行而不殆，可以為天下母。
:
吾不知其名，
:
字之曰道，
:
強為之名曰大。
:
大曰逝，
:
逝曰遠，遠曰反。
:
故道大，天大，地大，王亦大。
:
域中有四大，
:
而王居其一焉。
:
人法地，地法天，天法道，道法自然。
:

## 杳眇疏

杳眇曰：

道之為物，視之不見，聽之不聞，然萬物由之以生，天地由之以立。此章言道之體用，最為完整，學者不可不察。

夫帛書云「有物昆成」，王弼本作「有物混成」。杳眇竊謂「昆」之義長。昆者，渾淪之義，言道未剖之時，萬物一團而無間也。混則已涉於雜，昆則本然如是。[[有物昆成]]之義，所以明道先天地而生，浑然自存，非由湊泊。《[[大宗師]]》云：「夫道，有情有信，无為无形；自本自根，未有天地，自古以固存。」正此之謂。

次云「繡呵繡呵」，王弼本作「寂兮寥兮」。寂寥者，虛無之狀；繡繆者，糾纏之貌。二義相異，然皆所以言道之不可以形名求也。道之在天下，無所不貫，無所不周，如絲之繡物，如繩之糾繆，其用廣矣。《[[得一]]》篇云「一之理，施四海」，此之謂乎？

「吾未知亓名，字之曰道，吾強為之名曰大。」[[字之曰道]]，強名曰大，此聖人不得已而立言也。《[[道之可道非常道|道之可道非常道]]》云：「道之可道，非常道也。」道不可道，強以字名；名不可名，強以大稱。此非聖人之妄作，實以言道之玄妙，讀者當得意忘言可也。

「大曰筮，筮曰遠，遠曰反。」王弼本作「大曰逝，逝曰遠，遠曰反」。帛書多一「筮」字。杳眇以為，筮者，占問也，演化之義；逝者，往也，亦通。然道之演化，周流六虛，無有止息，故曰筮、曰遠、曰反。周而復始，往而必返，此道之常也。《易》曰：「無平不陂，無往不復。」其是之謂乎？

「道大，天大，地大，王亦大。國中有四大，而王居一焉。」[[域中有四大]]，人與天地同道，其位不可以小視之。此與[[法天]]之意相發明。《[[大宗師]]》又云：「知天之所為，知人之所為者，至矣。」王之所以大，以其能法地、法天、法道也。

「人法地，地法天，天法道，道法自然。」此[[人法地地法天]]之序也。萬物相法，由卑以至高。人法地，取其厚德無私；地法天，取其覆載無私；天法道，取其不宰有功；道法自然，取其自然而然，無為而成。《[[道法自然治]]》引[[得一]]之旨，謂聖人守一，抱樸含真，與道同體，其要亦不出此。

然杳眇有一說：帛書作「國中」，王弼本作「域中」。國者，有域之限；域者，無疆之稱。以道言之，域中為優；以人言之，國中亦可。要之，道無不在，彌綸宇宙，非方域所能限也。

嗚呼！道之在天下，大矣遠矣。聖人法之，修身治國，皆在其中。學者茍能會此「法」字之義，則[[道生天地]]、德被萬物之旨，思過半矣。

**警語**：
> 道法自然，自然者無為，無為者無不為。學者茍求之於外，不得之於內；茍執之於名，不得之於道。是以聖人貴一守真，與道遊焉。
