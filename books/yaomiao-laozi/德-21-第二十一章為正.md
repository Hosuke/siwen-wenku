# 德經第二十一章 · 為正

> 帛書第 21 章 · 王弼第 58 章

## 帛書原文

亓正閔閔 亓民屯屯 亓正察察 亓邦夬夬 

禍 福之所倚 福 禍之所伏 孰知亓極 

亓无正也 正復為奇 善復為訞 

人之迷也 亓日固久矣 

是以方而不割 兼而不刺 直而不紲 光而不耀

## 王弼本對校

其政悶悶，其民淳淳；
:
其政察察，其民缺缺。
:
禍兮福之所倚，福兮禍之所伏。孰知其極？其無正。
:
正復為奇，
:
善復為妖。
:
人之迷，其日固久。
:
是以聖人方而不割，
:
廉而不劌，
:
直而不肆，
:
光而不燿。
:

## 杳眇疏

杳眇曰：

此章之要，在論政治之寬猛與禍福之相倚，而終歸於聖人方正之德。帛書、王弼二本之異，竊嘗深考之矣。

夫「閔閔」與「悶悶」，義本相通，皆寬簡之意也。「屯屯」與「淳淳」，皆厚義。水之性柔，故能滋潤萬物而不爭；政治亦然，寬則民淳，猛則民缺。[[其政察察]]者，峻法繁令、苛察之政也，政令苛則民散，此[[無為而治]]之反也。聖人法水之德，不設科條，不煩政令，因民之自然而治之，是為善治。

至若「兼而不刺」，帛書之文也；王弼本作「廉而不劌」。兼者，兼容並蓄之謂；廉者，廉隅方正之謂。[[兼而不刺]]者，言聖人之量，廣而不侵也。[[方而不割]]者，方正而不傷物。[[光而不耀]]者，聖德內含，不以明耀炫人。[[直而不肆]]者，河上公曰：「直道而行，而不自放肆以侵物也。」是四者皆聖人[[聖人方正廉直]]之全德，而本乎不爭之心也。

「正復為奇，善復為訞」，此[[不爭故無尤]]之義也。夫人之有尤，由於爭；欲無尤者，必先去爭之心。是以[[為而不爭]]，乃全德之終也。

然帛書無「聖人」二字，直云「是以方而不割」，其義彌深。蓋此方正之德，非聖人獨有，乃道之固然也。[[上善若水]]，水善利萬物而不爭，此[[水善利萬物而不爭]]之旨，而方正之所自出也。

考之[[德經]]之義：拘校上古中古下古大德之善言，以類相從而成。聖人法水之德，其政閔閔，其民屯屯，[[不爭]]之心達於上下，則[[光而不耀]]之治成矣。

**警語**：禍福倚伏，正奇善訞，迷於分別，則日固久矣。唯不爭者，能方正而不割，兼而不刺，直而不肆，光而不耀——此道之用也。
