# 德經第二十一章 · 第二十二章 長生

> 帛書第 21 章 · 王弼第 58 章

## 帛書原文

（59）

治人事天 莫若嗇

夫唯嗇 是以蚤服 蚤服是謂重積德 重積德則无不克 无不克則莫知亓極 莫知亓極 可以有國 有國之母 可以長久

是謂深根固柢 長生久視之道也

## 王弼本對校

其政悶悶，其民淳淳；
:
其政察察，其民缺缺。
:
禍兮福之所倚，福兮禍之所伏。孰知其極？其無正。
:
正復為奇，
:
善復為妖。
:
人之迷，其日固久。
:
是以聖人方而不割，
:
廉而不劌，
:
直而不肆，
:
光而不燿。
:

## 杳眇疏

杳眇曰：

此章之要，在一「嗇」字。

夫嗇者，非徒節用之謂，乃聖人愛神斂智、歸根返朴之大道也。《老子河上公章句》有云：「嗇，愛也。治人事天無如愛精神也。」此得之矣。精神和而不散去，精神不散去，則[[重積德]]之功日厚。《韓非子·解老》嘗疏其義，謂聖人用神也靜，靜則少費，少費之謂嗇；衆人用神也躁，躁則多費，多費之謂侈。嗇之與侈，其效天淵。嗇則德不去，和氣日入；侈則神耗智竭，咎殃隨之。此[[嗇]]之實義，治人者不可不察也。

然今所傳[[老子 (帛書本) · 章八|帛書]]本與王弼本文字迥異，不可不辨。帛書此章首句云「治人事天莫若嗇」，以嗇為全章之宗，脈絡分明：由嗇而蚤服，由蚤服而重積德，由重積德而無不克，由無不克而莫知其極，由莫知其極而有國，由有國之母而長久，終見深根固柢之效。此一貫而下，如水之就下，如木之有根，理甚直截。

至若王弼本次章，則云「其政悶悶，其民淳淳」，又及[[方而不割|方而不割、廉而不劌、直而不肆、光而不燿]]之旨，似論[[聖人之知|聖人治世]]之方，與帛書治人事天之義旨趣各殊。杳眇竊以為，二本之異，非傳寫之誤，乃義理各有側重。帛書重修身，強調內德充實自然外及；王弼本次章重治道，言聖人方正端直之德行可以化物。合而言之，則修身為治平之本，治平為修身之驗，《[[大學]]》所謂「自天子以至於庶人，壹是皆以修身為本」，其義與此暗合。

[[天長地久|天地長久，以其不自生]]。《[[生之畜之]]》云「生而弗有，長而弗宰，是謂玄德」。聖人法之，退身而身先，外身而身存，不以其無私歟？故能成其私。嗇之為道，豈獨治人者然哉？修身、治國、理天下，胥本乎此。

嗇之要，在乎不多費神智也。人能嗇則[[幾於道|幾於道]]，能法水之善利萬物而不爭，則天下莫能與之争。[[不爭]]者，咎之門之闔也；嗇者，德之根之固也。二者相須，而此章之旨備矣。

夫嗇根於神靜，神靜根於思慮之不擾。世人馳騖名利，耗神以求，安得不怠？嗇以持之，靜以守之，深根固柢，長生久視，殆聖人示我以終身之術也。**學者苟能嗇其精神、守其柔弱，則根深柢固，與道長久，此乃千古不易之論，豈虛言哉？**
