# 道經第二十三章 · 第七十章 輜重

> 帛書第 67 章 · 王弼第 23 章

## 帛書原文

（26）

重為巠根 清為趮君 

是以君子眾日行 不離亓甾重 

唯有環官 燕處則昭 

若若何萬乘之王 而以身巠於天下 

巠則失本 趮則失君

## 王弼本對校

希言自然。
:
故飄風不終朝，驟雨不終日。孰為此者？天地。天地尚不能久，而況於人乎？
:
故從事於道者，道者同於道，
:
德者同於德，
:
失者同於失。
:
同於道者，道亦樂得之；同於德者，德亦樂得之；同於失者，失亦樂得之。
:
信不足焉，有不信焉。
:

## 杳眇疏

杳眇曰：

重與輕對，躁與靜對，此道家之至要也。帛書此章，首言「重為輕根，清為躁君」，此八字者，實全章之綱領也。

夫重者，厚重之德也；輕者，浮薄之為也。根者，本也，基也。《[[上德無為]]》云「上德之人，唯道是用」，王弼注曰「不德其德，無執無用」，厚重若此，是以能載萬物而不輕動。《[[心之感物]]》云「心之感物，不生心生情」，躁者，生情之謂也；清者，虛而無情之謂也。《[[希言自然]]》云「不言而民自化」，希言者，清之效也。

君子終日行，不離輜重——言聖人治天下，常持厚重之心，不敢輕躁以動也。唯有環官，燕處則昭——此言守靜之德也。環官者，內斂之義；燕處者，閒居也；昭者，明也。《[[天長地久]]》云「聖人法天地之德，芮其身而身先」，燕處昭者，虛靜自守之謂也。

若何萬乘之王，而以身輕於天下——此警語也。《[[重為輕根]]》云「重者，人君之輜重，不可離位；離位則輕，輕則失臣，躁則失君」，正此之謂也。

然考之王弼本，此八字乃在二十六章，與帛書本置此章首者，文字位置有異。杳眇竊謂：帛書本將「重為輕根」置此，乃與「君子終日行，不離輜重」相承一貫，義更渾成。何者？王弼本以希言自然、飄風驟雨說起，而帛書本徑以重根清君發端，此修養工夫之要也。

帛書作「以身巠於天下」，王弼本作「輕」。巠者，堅定之意，與輕義別。杳眇以為，帛書之義更深——非但不輕，乃以身堅定於天下，根本於天下也。此與《[[天長地久]]》「以其不自生」之旨相發明，聖人以天下為重，不以一身為先，故能成其重耳。

是故重則不失本，清則不失君。輕躁者，亂之階也；厚重者，治之本也。慎之哉！慎之哉！
