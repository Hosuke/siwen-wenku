# 道經第二十五章 · 第七十二章 恆德

> 帛書第 69 章 · 王弼第 25 章

## 帛書原文

（28）

知亓雄 守亓雌 為天下溪 為天下溪 恆德不離 恆德不離 復歸嬰兒 

知亓白 守亓辱 為天下浴 為天下浴 恆德乃足 德乃足 復歸於樸 

知亓白 守亓黑 為天下式 為天下式 恆德不忒 恆德不忒 復歸於无極 

樸散則為器 聖人用則為官長 夫大制无割

## 王弼本對校

有物混成，先天地生。
:
寂兮寥兮，獨立而不改，
:
周行而不殆，可以為天下母。
:
吾不知其名，
:
字之曰道，
:
強為之名曰大。
:
大曰逝，
:
逝曰遠，遠曰反。
:
故道大，天大，地大，王亦大。
:
域中有四大，
:
而王居其一焉。
:
人法地，地法天，天法道，道法自然。
:

## 杳眇疏

杳眇曰：

此章三「知」三「守」，示聖人脩道之階梯也。雄者剛健，雌者柔弱；聖人知剛強之可用，而守柔弱以自持，故能為天下溪。溪者，水之所歸，虛而能受，德之所以不離也。河上公注「溪」云：「溪，流水會歸之處。」聖人虛心下賢，若谷之虛，故百川歸之，德全而不失。復歸嬰兒者，返其純樸之初，性完而無偽也。

其次，知白守辱。白者昭明，辱者闇昧；聖人明知昭明之可貴，而守闇昧之質以自牧，故能為天下浴。浴者，萬物之所受焉。《[[復歸於樸]]》云「恒德乃足，復歸於樸」，言恒德充盈，則返乎太初未散之渾樸也。樸者，未雕之木，喻道之大全。

其次，知白守黑。白者明，黑者幽；聖人知昭明之可慕，而守闇昧以自晦，故能為天下式。式者，法也、表也。[[天下式]]者，聖人垂為楷模於天下，使萬物有所準的也。《[[知其雄守其雌]]》言雄雌之辨，此則兼言白黑，以見聖人智深而守淺，德盛而用謙也。復歸无極者，道體虛空，無所窮極，非有限之名所能限也。

「樸散則為器」者，樸者道之全，散之分者，則成萬物之器。聖人用之，則為官長，《[[得一]]》所謂「侯王得一以為天下正」也。

王弼本此章前有「有物混成，先天地生」一大段，帛書本皆無之。杳眇竊謂：帛書本文義完足，自「知其雄」至「大制无割」，一氣呵成，示脩道之要；王弼本增「有物混成」一段，論道之體，與「知雄守雌」義相發明，而篇章較繁。要之二者皆聖人脩德之學，未可以文字多少定優劣也。

末云「夫大制无割」，言聖人治世，其制至大，不以刑名割裂天下也。《[[大制無割]]》疏之詳矣，曰：「無為而治，不以政令分割萬物，各遂其性也。」

夫道之為德，貴在抱一。聖人知雄而守雌，知白而守辱、知白而守黑，由溪而浴而式，由嬰兒而樸而无極，是知天下之善守者，莫若聖人也。守之不失，則德全而道凝，天下孰能分之？

**警語**：守雌者能為天下溪，守黑者能為天下式，守之至則道全，道全則无割於天下矣。學者可不審諸？
