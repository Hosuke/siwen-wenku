## English

**Containing the World** (為天下容) is a celebrated passage from the Wenzi describing the nine qualities a ruler must cultivate to properly govern all under heaven. The text presents these as a comprehensive ideal of rulership.

The passage opens: "Those skilled at governing the world practice non-action; thus nothing is left undone. Therefore, when there is something to contain, one must be able to obtain it. Through non-action, one achieves merit; without this capacity, any movement will bring misfortune" (古之善為天下者，無為而無不為也，故為天下有容，能得其容，無為而有功，不得其容，動作必凶).

The nine qualities are then elaborated:
1. **冬涉大川** (crossing the great river in winter) — walking cautiously, never daring to advance rashly
2. **畏四鄰** (fearing the four neighbors) — guarding against injuries from all directions
3. **若容** (as if containing) — being humble and respectful
4. **若冰之液** (as if ice is melting) — never daring to accumulate or hoard
5. **若樸** (as if uncarved wood) — never daring to appear accomplished or successful
6. **若濁** (as if turbid water) — never daring to be clear or bright
7. **若谷** (as if a valley) — never daring to be full or abundant

The underlying philosophy: "The Dao withdraws, thus it can be first; it guards softness and weakness, thus it can be proud; it humbles itself, thus it can be above others; it diminishes itself, thus it can be firm; it yields, thus it can be whole; it dwells in impurity, thus it can be fresh; it sees insufficiency, thus it can be wise" (道，退故能先，守柔弱故能矜，自卑下故能高人，自損弊故實堅，自虧缺故盛全，處濁辱故新鮮，見不足故能賢).

## 中文

**為天下容**出自《[[文子]]》，乃描述君主治理天下所須具備之九種德行，構成了道家聖王政治的完整理想。

原文云：「古之善為天下者，無為而無不為也，故為天下有容，能得其容，無為而有功，不得其容，動作必凶。」此為全篇之綱領，繼而詳述九容：

一、**冬涉大川**——不敢行，退讓而不争先；
二、**畏四鄰**——恐自傷，守柔弱而不矜傲；
三、**若容**——謙恭敬，自卑下而敬人；
四、**若冰之液**——不敢積藏，自損弊而不堅持；
五、**若樸**——不敢廉成，自虧缺而不敢保全；
六、**若濁**——不敢明清，處濁辱而不敢求鮮；
七、**若谷**——不敢盛盈，見不足而不敢自賢。

其義理淵源於[[無為而治]]與[[清靜之治]]，而更進一層：非消極之無為，乃積極之「容」——以虛廣之德容納天下萬物。此與[[真人]]之境界相通，亦與[[虛無恬淡]]互為表裡。

## 日本語

**為天下容**とは、『文子』における天下を統治する君主が身に付けるべき九つの徳性を描写した有名な一節であり、道家の聖王政治の完全な理想を提示している。

本文は「古之善為天下者、無為而無不為也、故為天下有容、能得其容、無為而有功、不得其容則び動作必凶」（昔、天下を善く治めた者は、無為にして為すことなきことなし、故に天下に容れあれば、其の容れを得て、無為にして功あり、其の容れを得ざれば、動くこと必ず凶）と始まる。

九つの徳性は以下のように詳述される：
一、**冬涉大川**——不敢行、躊躇し、敢えて先を争わない
二、**畏四鄰**——恐自傷、柔らかく弱いものを守って驕らない
三、**若容**——謙恭敬、まず自分を卑くして他人を敬う
四、**若冰之液**——不敢積藏、自ら損耗して堅持しない
五、**若樸**——不敢廉成、自ら欠けて全うしようとしない
六、**若濁**——不敢明清、汚辱の中にいて鮮やかさを求めない
七、**若谷**——不敢盛盈、不足を見て自ら賢いと言い張らない

[[無為而治]]と[[真人]]の境地と通じ、虚無恬淡の精神と表裏一体を成す。
